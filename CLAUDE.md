Fixed a **data-loss bug in the Portfolio admin** discovered while building the Product module. `admin/pages/portfolio/_form.blade.php` rendered each gallery image's "Remove" control as its own `<form>` — but that partial is `@include`d *inside* the main `<form>` in `create.blade.php`/`edit.blade.php`, so they were nested forms. HTML forbids nesting, and the parser's recovery made this far worse than a dead button: the first nested `<form>` start tag is dropped (so its `@csrf`/`@method('DELETE')` hidden inputs and its Remove button were absorbed into the outer *update* form), and its `</form>` end tag closed the outer form early (orphaning the "Update Project" button, which then had no form owner and did nothing when clicked). The absorbed inputs left the update form carrying three `_token`s and three `_method` values — `PUT`, `DELETE`, `DELETE` — and since PHP keeps the *last* value for duplicate field names, the form resolved to `_method=DELETE` against `action="/admin/portfolio/{slug}"`, which is a real route (`portfolio.destroy`). Net effect, reproduced and confirmed against a throwaway project: **clicking "Remove" on the first gallery image deleted the entire portfolio project**, images and all. Only the second and later images' Remove buttons worked, since by then the parser had a clean slate. The bug was invisible until now because `PortfolioSeeder` seeds zero images, so the gallery block never rendered for any seeded project. Fixed the **mobile menu (offcanvas drawer)**, which had two independent bugs. (1) The drawer rendered as an 84px-tall sliver pinned to the header instead of a full-height panel: its markup sat *inside* `<header class="site-header">`, and that element carries `backdrop-filter: blur(12px)`, which per spec makes it a **containing block for `position: fixed` descendants** — so Bootstrap's `.offcanvas` (`top:0; bottom:0`) resolved against the 84px header box rather than the viewport, clipping the body to a 32px scroll area with all 8 nav links and the CTA effectively unreachable. (2) Tapping "Get Free Consultation" inside the drawer opened the consultation modal but left the drawer open behind it with two stacked backdrops, and threw `Bootstrap doesn't allow more than one instance per element.
