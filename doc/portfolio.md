# CodexeHub Portfolio Page Design Prompt

## Objective

Design a **premium, modern, enterprise-level Portfolio Page** for **CodexeHub**, a software development company.

The design should follow the same visual language as the homepage:

* Modern SaaS
* Enterprise
* Minimal
* Professional
* Spacious
* Clean UI
* High-quality UX
* Fully responsive
* Reusable Bootstrap components

The portfolio page should focus on showcasing completed software projects, case studies, and technical expertise while encouraging visitors to contact CodexeHub.

---

# Technology

Create using

* Latest Laravel (Blade Template)
* Bootstrap 5.x
* HTML5 only
* SCSS
* JavaScript
* Bootstrap Icons

**Important**

* No backend code.
* No PHP logic.
* No MySQL queries.
* Design layout only.
