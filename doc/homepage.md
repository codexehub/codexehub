## Project Overview

Create a modern, premium, enterprise-grade software company website named CodexeHub using the latest Laravel (Blade Template) with Bootstrap 5.x, SCSS, and MySQL.

The goal is to build a production-ready, reusable, modular boilerplate that can be used as the foundation of the entire website.

## Important:

1. Generate HTML only (Bootstrap syntax).
2. Build reusable HTML layouts that can later be converted into Blade partials.
3. Focus on frontend structure only.
4. No backend functionality.
5. No database queries.
6. No authentication.
